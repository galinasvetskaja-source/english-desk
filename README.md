# English Desk

Личный кабинет ученика английского, который открывается внутри Telegram (Mini App бота @hwdeckbot).

- `index.html` — сам кабинет (домашка, слова с играми и интервальным повторением, баланс уроков).
- `config.js` — адрес сервера и имя бота.
- `backend/Code.gs` — серверная часть для Google Apps Script. Хранит данные в Google Таблице
  и проверяет, что каждый запрос пришёл из Telegram от конкретного человека. Токен бота
  хранится только в свойствах скрипта, в этом репозитории его нет.

## Как всё устроено

- Первый человек, открывший кабинет, становится учителем (его Telegram id записывается
  в свойство скрипта `TEACHER_ID`).
- Учитель добавляет ученика и отправляет ему личную ссылку `https://t.me/hwdeckbot?startapp=<код>`.
  Ученик открывает её, и кабинет привязывается к его Telegram.
- Если ученик открыл бота без ссылки, он появляется у учителя в списке «Открыли бота без ссылки».
- Настройки кабинета (вкладка ⚙): стиль, язык кабинета (английский или русский) и режимы повторения слов
  (интервальное повторение и шесть игр: каждый включается и выключается). Ученик меняет их у себя, учитель —
  у выбранного ученика; настройки общие и хранятся в листе «Ученики» (колонки `lang`, `skin`, `modes_off`).
  Нельзя выключить все режимы сразу. Учитель всегда видит кабинет на русском и выбирает свой стиль отдельно
  (на своём устройстве). Язык подсказок к словам (RU + EN / EN + EN) ученик выбирает на вкладке «Слова».
- Листы таблицы: Ученики, Домашка, Слова, Занятия, Оплаты, Прогресс, Ответы ДЗ, Ожидают.

## Формат ДЗ с автопроверкой

Учитель вставляет ДЗ в кабинете через «+ Вставить ДЗ от Claude». Это JSON-объект
(или массив объектов):

```json
{
  "title": "Past Simple: my weekend",
  "date": "2026-11-03",
  "focus": "Past simple, regular and irregular verbs",
  "tasks": [ ... ]
}
```

`title` и `tasks` обязательны; `date` (ГГГГ-ММ-ДД) по умолчанию сегодня; `focus` — короткое
описание по-английски. Тексты для ученика пишутся по-английски.

Общие поля задания: `type`, `num` (номер), `title`, `instr` (инструкция), необязательные
`rule` (правило в рамке), `passage` (текст для чтения, абзацы через пустую строку),
`bank` (массив слов для подсказки).

| type | items | Пример пункта |
|---|---|---|
| `gap` | пропуски в `{{ }}`, варианты через `\|` | `{"s": "She {{went}} home and {{had\|ate}} dinner."}` |
| `choice` | варианты `o`, номер правильного `a` (с 0) | `{"s": "I ___ tired.", "o": ["am", "is"], "a": 0}` |
| `tf` | `a`: true/false | `{"s": "Tom lives in Paris.", "a": false}` |
| `match` | левая часть `l`, правильная правая `r`; у задания можно дать `options` | `{"l": "big", "r": "large"}` |
| `transform` | начало `start`, правильные ответы `a` (строка или массив) | `{"s": "He is tall. (comparative)", "start": "He is", "a": ["He is taller"]}` |
| `open` | свободный ответ, подсказка `ph` | `{"s": "What did you do on Sunday?"}` |
| `link` | без items: `url`, `text`, `label` | `{"type": "link", "title": "Watch first", "url": "https://…", "label": "Open video ↗"}` |

Проверка ответов не учитывает регистр, лишние пробелы и точку в конце.

## Формат слов

«+ Вставить список слов»: по одной строке на слово

```
take off — to leave the ground — взлетать — The plane {{took off}} at six.
```

(слово — простое объяснение по-английски — перевод — пример). Разделители: ` — `, ` - `, `|`
или табуляция. Если слово в примере не взято в `{{ }}`, кабинет попробует найти его сам.
Можно вставить и JSON-массив `[{"word","meaning","ru","example"}]`.

## Стили кабинета

- Три стиля: «Рисунки» (по умолчанию: лавандовый фон, толстые чёрные контуры, яркие плоские цвета, предметы с улыбками и звёздочки), «Игра» (тёмный, неон, пиксели) и «Элегантный» (butter yellow, нежно-голубой, шрифты с засечками).
- Все стили лежат в `skins.css`. Включаются атрибутом `<html data-skin="doodle|game|elegant">`, каждый переопределяет те же переменные цветов и шрифтов.
- Ученик выбирает стиль кружками под приветствием (выбор хранится в его браузере). Учитель задаёт стиль по умолчанию для ученика в фиолетовой панели («Стиль»), значение хранится в колонке `skin` листа «Ученики».
- После обновления `backend/Code.gs` нужно заново опубликовать скрипт (новая версия веб-приложения), иначе выбор стиля учителем не сохранится. Сам переключатель у ученика работает и без этого.
